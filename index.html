Menitgaming Uploader

Internal publishing tool for the YouTube channel @menitgaming.

What this tool is

A private, single-operator utility that uploads video files owned by the channel operator to the channel itself. It is not a service, has no users other than the channel owner, and is not distributed.

Google API usage

It requests exactly one OAuth scope: https://www.googleapis.com/auth/youtube.upload. It cannot read, modify or delete existing channel data, and it cannot access any other Google account.
